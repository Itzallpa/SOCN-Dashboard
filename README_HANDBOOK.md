# 📖 คู่มือการใช้งาน SOC Dashboard & Online Tunnel (User Handbook)

ยินดีต้อนรับสู่ **SOC Operations Dashboard** ระบบสรุปผลพัสดุขาออกล่าช้า (Outbound Late Summary) และระบบติดตามการสแกนพัสดุ (Skip Process Monitor)

---

## 🌐 เลือกรันออนไลน์ตามเครือข่ายเน็ตที่ใช้งาน

เน็ตแต่ละที่อาจมีระบบความปลอดภัยต่างกัน เลือกดับเบิ้ลคลิกไฟล์ให้เหมาะกับเน็ตที่ใช้:

| เครือข่ายเน็ต | ไฟล์ที่ต้องใช้ | คำอธิบาย |
| :--- | :--- | :--- |
| **🏠 เน็ตบ้าน / Hotspot มือถือ** | **`run_dashboard.bat`** | รันผ่าน Cloudflare Tunnel ลิงก์ `trycloudflare.com` |
| **🏢 เน็ตบริษัท (Company Network)** | **`run_company_network.bat`** | รันผ่าน SSH Tunnel ทะลุไฟร์วอลล์บริษัท ลิงก์ `pinggy.link` |

---

## 💻 รวมคำสั่งสำหรับพิมพ์รันเอง (Command Cheatsheet)

### 🏢 1. สำหรับเน็ตบริษัท (Bypass Firewall ทะลุบล็อก 100%):
```cmd
ssh -R 80:localhost:5000 free.pinggy.io
```
> ระบบจะสุ่มลิงก์ HTTPS เช่น `https://xxxx.free.pinggy.link` ก๊อปปี้ไปเปิดดูบนมือถือได้ทันที

---

### 🏠 2. สำหรับเน็ตบ้าน / Hotspot มือถือ (Cloudflare):
```cmd
cloudflared.exe tunnel --protocol http2 --url http://localhost:5000
```

---

### 💻 3. คำสั่งเปิดรันระบบ Flask Server (Dashboard):
```cmd
python app.py
```

---

## 🚀 1. วิธีเปิดใช้งานใน 1 คลิก (Quick Start)

1. ดับเบิ้ลคลิกไฟล์ทางลัดในโฟลเดอร์ `OB Dashboard`:
   - ใช้เน็ตบริษัท → ดับเบิ้ลคลิก **`run_company_network.bat`**
   - ใช้เน็ตทั่วไป → ดับเบิ้ลคลิก **`run_dashboard.bat`**
2. ระบบจะเปิด 2 หน้าต่างให้อัตโนมัติ (Server + Tunnel)
3. สังเกตลิงก์ HTTPS ในจอดำ ก๊อปปี้ไปเปิดดูบนมือถือ/ไอแพดได้ทันที

> ⚠️ **ข้อควรจำ:** ต้องเปิดหน้าจอดำทิ้งไว้ตลอดการใช้งาน เมื่อเลิกใช้งานกดปิดหน้าจอดำได้เลย

---

## 📦 2. การใช้งาน Tab 1: Outbound Late Summary

หน้านี้ใช้สำหรับติดตามพัสดุที่หลุดเวลา Cutoff รอบที่ 2

* **📁 สลับไฟล์ดูข้อมูล:** กดคลิกที่กล่องดรอปดาวน์ด้านบนสุด `📁 เลือกไฟล์ดูข้อมูล` เพื่อเลือกเปลี่ยนไฟล์ CSV รายวันเดิมที่เคยอัปโหลดไว้
* **📤 อัปโหลดไฟล์ CSV ใหม่:** ลากไฟล์ CSV มาวางในกล่องลากวาง (Drag & Drop) หรือกดปุ่ม `เลือกไฟล์ CSV` ระบบจะประมวลผลให้อัตโนมัติ
* **📋 ดู Raw Data:** สามารถกดคลิกที่ชื่อสถานีในตาราง Top 10 หรือกดปุ่ม `📋 ดู Raw Data` เพื่อเปิดหน้าต่างค้นหาและ Export รายการพัสดุเป็น CSV ได้

---

## ⚠️ 3. การใช้งาน Tab 2: Skip Process Monitor & Volume Tracker

หน้านี้ใช้สำหรับคุมเข้มเป้าหมายการสแกนพัสดุไม่ให้เกินเป้าหมายภาพรวม **< 0.80%** (ราย Zone A, B, C **< 0.27%**)

### 📊 ขั้นตอนการใช้ Volume Tracker (SOCN Actual)
1. **กรอกข้อมูลใหม่:**
   - เลือก **วันที่**
   - กรอก **SOCN Actual** (ดูจากแถว Row 10 ใน Performance Dashboard Google Sheet)
   - กดปุ่ม **`💾 บันทึก`** (ข้อมูลจะถูกเซฟเก็บไว้ในเครื่องถาวร)
2. **เลือกใช้วันที่เคยบันทึกไว้:**
   - กดคลิกที่ดรอปดาวน์ **`📌 เลือกวันที่บันทึกไว้`**
   - เลือกวันที่ต้องการ ระบบจะดึงตัวเลข SOCN Actual วันนั้นมาเป็นตัวหารคำนวณ `% Skip` ทันที

### 🎯 การดูผลลัพธ์ราย Zone
- ตารางจะแสดงเฉพาะ 6 หมวดหมู่หลัก: **`ALL`**, **`A`**, **`B`**, **`C`**, **`INTERSOC`**, **`RETURN`**
- ตัวเลข `%` จะแสดง **สีเขียว 🟢** หากผ่านเกณฑ์ และ **สีแดง 🔴** หากเกินเป้าหมาย
- สามารถกดที่ตัวเลข Skip Count เพื่อเปิดดูรายการ Raw Data รายเคสได้ทันที

## 🛠️ 4. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

| ปัญหา | วิธีแก้ไข |
| :--- | :--- |
| **สลับไฟล์แล้วข้อมูลในหน้าเว็บไม่เปลี่ยน** | กด `Ctrl + Shift + R` หรือ `F5` เพื่อ เคลียร์แคชเบราว์เซอร์ |
| **อยู่เน็ตบริษัทแล้วลิงก์เข้าไม่ได้** | ใช้ไฟล์ **`run_company_network.bat`** แทน |
| **อัปโหลดไฟล์ CSV แล้วขึ้น Error** | ตรวจสอบว่าไฟล์เป็นนามสกุล `.csv` และมีคอลัมน์มาตรฐานครบถ้วน |
