แบบอัตโนมัติ (แนะนำ) — Login ครั้งเดียว ไม่ต้องใส่ cookie อีก
  1. กด Login SPX → จะมีหน้าต่าง Chrome เปิดขึ้นที่เครื่อง Server
  2. Login SPX ในหน้าต่างนั้นให้เข้าหน้า Outbound Monitor ได้
  3. กลับมากด Login เสร็จแล้ว — หน้าต่างจะปิด แล้ว Server ต่ออายุ cookie เองเบื้องหลัง
หรือใส่ cookie เอง (แบบเดิม)
  1. เปิด SPX Outbound Monitor → กด F12 → แท็บ Network → กด Search ในหน้า SPX 1 ครั้ง
  2. คลิก request list?outbound_station=2621... → แท็บ Headers → เลื่อนลงไปที่ Request Headers → แถว cookie → คลิกขวา → Copy value
  3. วางในช่องด้านล่าง แล้วกด บันทึก + ทดสอบ
cookie คือการ Login SPX ของคุณ — Server ใช้ดึงเฉพาะหน้า Outbound Monitor · แบบนี้หมดอายุในไม่กี่ชั่วโมง
